# Bio Extractos Medicinales

Bio Extractos Medicinales is a production-oriented informational website built as part of the Deep Brain Reset web portfolio.

## Overview

The project focuses on responsive presentation, polished motion, and component-based React implementation for a real-world business use case.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- GSAP
- Motion
- Node.js / Express dependencies
- Google Gemini integration capability

## Development Approach

The project was developed with an AI-assisted engineering workflow. AI tools accelerate implementation, debugging, refactoring, and iteration, while product direction, architecture, integration, testing, and final delivery remain under human supervision.

## Local Development

```bash
npm install
npm run dev
```

Type checking:

```bash
npm run lint
```

Production build:

```bash
npm run build
```

## Security

Runtime secrets and local `.env` files are excluded from version control. The public environment example contains placeholders only.
